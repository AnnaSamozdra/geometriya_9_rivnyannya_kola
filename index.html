1. Основна теорія

Що таке коло?

Коло — це множина всіх точок площини, які знаходяться на однаковій відстані від заданої точки. Ця задана точка — центр кола, а однакова відстань — радіус.

Рівняння кола з центром Q(a; b) і радіусом r

(x − a)² + (y − b)² = r²

Тут (a; b) — координати центра, r — радіус, а (x; y) — координати будь-якої точки кола.

Зверни увагу на знаки! У рівнянні (x − 3)² + (y + 2)² = 25 центр має координати Q(3; −2), а не Q(−3; 2).

Якщо центр — початок координат

x² + y² = r²

Наприклад, x² + y² = 49 — коло з центром O(0; 0) і радіусом 7.

2. Алгоритми розв'язування

Тип 1. Знайти центр і радіус за рівнянням

  1. Порівняй рівняння з формулою (x − a)² + (y − b)² = r².
  2. Визнач координати центра: Q(a; b). Пам'ятай про протилежні знаки в дужках.
  3. Знайди радіус: r = √(число праворуч).

Тип 2. Скласти рівняння за центром і радіусом

  1. Запиши загальну формулу кола.
  2. Підстав координати центра замість a і b.
  3. Піднеси радіус до квадрата та запиши праву частину.

Тип 3. Перетворити загальне рівняння

  1. Згрупуй доданки з x та з y.
  2. Виділи повні квадрати: до x² + px додай (p/2)²; до y² + qy додай (q/2)².
  3. Перенеси додані числа в праву частину.
  4. Порівняй із канонічним виглядом і визнач центр та радіус.

Тип 4. Скласти рівняння, якщо задано діаметр

  1. Знайди центр кола — середину діаметра.
  2. Знайди радіус — відстань від центра до одного з кінців діаметра.
  3. Підстав центр і r² у формулу рівняння кола.

3. Розібрані приклади

Приклади відповідають основним типам завдань параграфа. Читай кожен крок і звертай увагу на знаки.

Приклад 1. Знайти центр і радіус кола

(x + 2)² + (y − 3)² = 25

  1. Запишемо рівняння у вигляді: (x − (−2))² + (y − 3)² = 5².
  2. Координати центра: Q(−2; 3).
  3. Радіус: r = √25 = 5.

Відповідь: Q(−2; 3), r = 5.

Приклад 2. Виділити повні квадрати

x² + y² − 8x + 6y − 10 = 0

  1. Згрупуємо доданки: (x² − 8x) + (y² + 6y) = 10.
  2. Доповнимо до квадратів: (x² − 8x + 16) + (y² + 6y + 9) = 10 + 16 + 9.
  3. Запишемо квадрати двочленів: (x − 4)² + (y + 3)² = 35.
  4. Порівняємо з формулою: центр Q(4; −3), радіус r = √35.

Відповідь: Q(4; −3), r = √35.

Приклад 3. Скласти рівняння кола за кінцями діаметра

A(−5; 7), B(3; 11)

  1. Знайдемо центр — середину AB: xQ = (−5 + 3) : 2 = −1; yQ = (7 + 11) : 2 = 9.
  2. Отже, Q(−1; 9).
  3. Знайдемо квадрат радіуса: r² = (−1 − (−5))² + (9 − 7)² = 4² + 2² = 20.
  4. Підставимо у формулу: (x − (−1))² + (y − 9)² = 20.

Відповідь: (x + 1)² + (y − 9)² = 20.

Приклад 4. Чи належить точка колу?

Коло задано рівнянням x² + y² = 25. Перевіримо точку A(3; 4).

  1. Підставимо координати точки: 3² + 4² = 9 + 16 = 25.
  2. Отримали правильну рівність.
  3. Отже, точка A належить колу.

Відповідь: так, належить.

Приклад 5. Точка всередині, на колі чи зовні?

Коло: (x − 1)² + (y + 5)² = 16. Центр Q(1; −5), r² = 16.

Для точки A(4; −2): (4 − 1)² + (−2 + 5)² = 9 + 9 = 18.

Оскільки 18 > 16, точка лежить поза кругом.

Порівнюй отримане число з r²: менше — всередині круга; дорівнює — на колі; більше — поза кругом.

Приклад 6. Знайти відстань між центрами двох кіл

Кола задані рівняннями x² + (y − 2)² = 4 та (x + 1)² + (y − 4)² = 24.

  1. Центри: Q₁(0; 2), Q₂(−1; 4).
  2. Відстань: Q₁Q₂ = √((−1 − 0)² + (4 − 2)²).
  3. Q₁Q₂ = √(1 + 4) = √5.

Відповідь: √5.

4. Тренувальні вправи

Виконуй завдання послідовно. Відповіді вводь у поле. Для координат використовуй формат, зазначений у завданні. Після перевірки прочитай пояснення.

Твій прогрес
Правильних відповідей: 0 із 20

Після виконання всіх вправ дай собі відповіді:

  • Чи вмію виділяти повні квадрати?
  • Чи можу скласти рівняння кола за центром і радіусом або за кінцями діаметра?
